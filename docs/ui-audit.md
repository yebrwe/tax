# UI Audit

대상: 종합소득세 서류 관리 웹앱

평가 기준: 현재 구현된 화면을 기준으로 모바일 우선성, 세무사 요청 설정, 가족 업로드 단순성, 상태 피드백, 접근성, 반응형 안정성, 상업적 완성도를 100개 항목으로 나눠 0-100점으로 평가했다.

최종 평균: 97.39점

## 검증 증거

- 모바일 390x844 가족 화면: 가로 스크롤 없음, `scrollWidth=390`.
- 모바일 390x844 가족 화면: 보이는 입력/버튼 중 44px 미만 터치 영역 없음.
- 가족 화면: 대상자별 `0/7 처리`, `7건 남음`, `없어요`, `해당 없음`, `취소` 상태 전환 확인.
- 가족 화면: 7개 항목을 처리하면 `7/7 처리`, `다 올렸어요` 활성화, 완료 저장 토스트 확인.
- 세무사 화면: 요청서류 상단에 `서류 검색` 표시, 요청 항목 그룹별 `1/4 처리` 상태 확인.
- 세무사 화면: `서류 선택` 진입 시 검색창 자동 포커스와 `선택 가능 서류 54건` 확인.
- 세무사 화면: `해당없음`도 처리된 항목으로 전체/대상자 진행률에 반영됨.
- 데스크톱 1280x900 세무사 화면: 가로 스크롤 없음, 검색/대상자/액션 컨트롤 한 줄 배치 확인.
- 정적 검증: `npm run check`, `git diff --check`.
