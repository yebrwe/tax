# UI Audit Evidence

대상: 종합소득세 서류 관리 웹앱

## 정정

기존 `97.39점` 평가는 폐기한다. 사용자 제보 화면에서 `현재 목록 해제` 버튼이 흰색에 가까운 글자/밝은 배경으로 보였고, 이는 대비와 시인성 항목을 97점대로 줄 수 없는 명확한 반례다.

이번 수정에서 확인한 원인은 이전 어두운 세무사 사이드바용 CSS가 남아 `body[data-role="accountant"] .wide-button.neutral`에 흰 글자와 투명 배경을 적용한 것이다. 현재 밝은 카드형 세무사 컨트롤 UI와 충돌했다.

- E02 상태에서 `현재 목록 해제`: color `rgb(25, 31, 40)`, background `rgb(255, 255, 255)`, border `rgb(209, 214, 219)`, 크기 `172x46`.

- E03 검색: `의료` 입력 시 `선택 가능 서류 2건`, 결과 `연말정산 간소화 PDF 전체`, `의료비 연말정산 PDF`.

- 100개 전 항목에 대해 각각 별도 캡처와 자동 검증값을 붙인 상태는 아니다.
- 실제 Vercel 프로덕션 URL에서 Blob 업로드 성공까지 캡처한 증거는 아직 없다.
- 디자인 완성도를 97점 이상으로 주장하려면 버튼 대비 외에도 간격, 색상 토큰, 정보 밀도, 모바일 스크롤 길이에 대한 추가 개선과 추가 캡처가 필요하다.
