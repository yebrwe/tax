# 종합소득세 서류 관리

종합소득세 신고 준비서류를 개인·법인 대상자별로 관리하는 모바일 중심 정적 웹앱입니다. 브라우저 `localStorage`에 저장되며, JSON 백업으로 내보내고 다시 불러올 수 있습니다.

기본 체크리스트는 국세청 종합소득세 신고 안내의 제출대상서류, 소득공제·세액공제 증빙, 장부기장의무 관련 자료를 바탕으로 구성했습니다.

## 주요 기능

- 대상자별 진행률과 전체 진행률 확인
- 신고 제목, 귀속연도, 신고연도, 신고월을 작업방별로 설정
- 세무사가 `서류 선택` 모드에서 필요한 서류만 고르면 모든 대상자에게 일괄 적용
- 세무사가 직접 항목을 추가할 때는 요청 대상, 서류명, 발급처, 메모만 입력
- 대상자는 업로드 링크에서 개인 또는 법인을 고르고 파일만 업로드
- 대상자는 요청서류에 파일을 업로드하고, 세무사는 같은 작업방에서 파일 링크를 열어 다운로드
- 기본/신고, 소득자료, 사업/프리랜서, 부동산임대, 공제/감면, 가족/인적공제 카테고리 필터
- 파일 업로드 여부에 따라 미완료/완료 상태 자동 반영
- 서류별 요청 메모, 내부 메모, 파일명 기록
- 요약 복사, JSON 백업/복원, 인쇄
- 모바일에서 한 대상자씩 빠르게 확인하도록 기본 필터와 카드 레이아웃 최적화

## Vercel 배포

파일 업로드를 쓰려면 Vercel 프로젝트에 Blob Store를 연결해야 합니다. Vercel Dashboard에서 Storage > Blob을 생성/연결하면 `BLOB_READ_WRITE_TOKEN` 환경변수가 프로젝트에 추가됩니다.

루트 주소로 접속하면 `세무사`와 `일반 사용자` 진입 화면이 먼저 표시됩니다. 세무사는 설정 후 `업로드 링크 복사` 버튼으로 대상자용 링크를 공유합니다.

### GitHub로 배포

1. 이 폴더를 GitHub 저장소로 올립니다.
2. Vercel에서 `Add New Project`를 선택하고 저장소를 가져옵니다.
3. Framework Preset은 `Other`로 둡니다.
4. Build Command와 Output Directory는 비워둡니다.
5. Deploy를 누릅니다.

### CLI로 바로 배포

```bash
npx vercel
npx vercel --prod
```

처음 실행할 때 Vercel 로그인과 프로젝트 연결을 진행하면 됩니다.
